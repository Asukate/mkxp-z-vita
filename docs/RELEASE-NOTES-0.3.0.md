# HardRPG 0.3.0 Alpha

Released October 14, 2026.

## Faster

- Smoother maps and much faster menus and battles. In testing, BLACK SOULS
  menus close in under half a second, and To the Moon runs at about 30 FPS
  instead of 19.
- Much lower graphics memory use per sprite. Large games such as To the Moon
  no longer run out of graphics memory.
- The app starts, finds your games and returns from a game faster.

## More games

- RPG Maker 2000 and 2003 games, through a bundled EasyRPG Player.
- Games made for the desktop version of mkxp run as they come, such as
  To the Moon.
- LISA: The Painful (original VX Ace edition) now plays.
- MIDI music plays with a built-in General MIDI sound bank.

## Controls, per game (Triangle → Controls)

- Map any Vita button to an RPG Maker button or to any keyboard key, chosen
  from an on-screen keyboard. Games made for a PC keyboard become playable.
- Use the touch screen or rear pad as buttons: the whole surface, left and
  right halves, or four corners. Nothing is drawn over the game.
- Tap to walk: tap a spot on the map and your character walks there
  (XP, VX and VX Ace games with normal tile movement).
- Run toggle, right-stick mouse pointer and a live input tester.

## Launcher

- Triangle on a game opens its own settings: controls, display, audio/MIDI and
  an optional FPS overlay.
- The library is scanned automatically when the app starts.
- Remove from library (Triangle): takes a game off the list, then asks
  whether to delete its files and, for a ZIP game, its unpacked copy.
- A ZIP game stays in the list after its ZIP is deleted and plays from its
  unpacked copy, so the ZIP no longer has to take up space twice. Triangle →
  Delete the ZIP, keep the game does this from the app.
- A notice when a newer HardRPG is released, with its changelog. It can be
  turned off in Settings → Release checks.
- The version is shown on the LiveArea screen before you open the app.
- Error reports include more detail to help fix crashes.

## Known issues

- Pokémon Essentials games (such as Pokémon Infinite Fusion) do not run yet.

This is still an alpha: compatibility and speed vary by game. See the
[compatibility list](COMPATIBILITY.md).
